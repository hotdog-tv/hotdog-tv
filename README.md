# Hotdog TV

The Hotdog TV website, https://hotdog-tv.github.io/: the download page, published builds of
Hotdog TV, and the small files its built-in update check reads.

| | |
|---|---|
| [`latest.apk`](https://hotdog-tv.github.io/latest.apk) | Android TV / Fire TV — the newest release |
| [`HotdogTV-Setup.exe`](https://hotdog-tv.github.io/HotdogTV-Setup.exe) | Windows — installer |
| [`HotdogTV-portable-win64.zip`](https://hotdog-tv.github.io/HotdogTV-portable-win64.zip) | Windows — unzip and run, nothing installed |
| [`HotdogTV.dmg`](https://hotdog-tv.github.io/HotdogTV.dmg) | Mac |
| [`HotdogTV-x86_64.AppImage`](https://hotdog-tv.github.io/HotdogTV-x86_64.AppImage) | Linux |
| [`HotdogTV-Sync-Setup.exe`](https://hotdog-tv.github.io/HotdogTV-Sync-Setup.exe) | Windows — the sync server (optional: keeps your devices in step) |
| [`changelog.html`](https://hotdog-tv.github.io/changelog) | What's new |

This repository has no source code and no history: it is replaced at every release.
