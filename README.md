# Hotdog TV downloads

Published builds of Hotdog TV, and the small files its built-in update check reads.

| | |
|---|---|
| `hotdogtv/latest.apk` | Android TV / Fire TV — the newest release |
| `hotdogtv/HotdogTV-Setup.exe` | Windows — installer |
| `hotdogtv/HotdogTV-portable-win64.zip` | Windows — unzip and run, nothing installed |
| `hotdogtv/HotdogTV-Sync-Setup.exe` | Windows — the sync server (optional: keeps your devices in step) |
| `hotdogtv/changelog.html` | What's new |

This repository has no source code and no history: it is replaced at every release.
