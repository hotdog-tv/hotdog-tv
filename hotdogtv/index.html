Android TV & Fire TV This device

Fire TV, Google TV, Nvidia Shield and other Android TV boxes, Android 7.0 or newer.

What's new

Download
  1. On the TV box, install the Downloader app (by AFTVnews) from the Amazon Appstore or Google Play.
  2. Let Downloader install apps. Fire TV: Settings › My Fire TV › Developer options › Install unknown apps › Downloader: On. No Developer options? Go to Settings › My Fire TV › About and press Select on the device name seven times. Google TV / Android TV: Settings › Apps › Security & restrictions › Unknown sources › Downloader: On. On a Shield it's under Settings › Device Preferences › Security & restrictions.
  3. Open Downloader, type this address and press Go: dl.auiptv.xyz/hotdogtv/latest.apk
  4. Choose Install, then Open. When Downloader offers to delete the downloaded file, you can.

From then on Hotdog TV updates itself: it tells you when a new version is out.

Windows This device

Windows 10 or 11, 64-bit. Or the portable zip, which needs no installing.

Download
  1. Run HotdogTV-Setup.exe and follow the steps.
  2. If Windows says “Windows protected your PC”, choose More info, then Run anyway. The installer isn't signed with a paid certificate, so Windows doesn't recognise it yet.
  3. Rather not install anything? Take the portable zip, unzip it somewhere you can write to (Desktop or Documents, not Program Files) and run Hotdog TV.exe in the Hotdog TV folder.

The app offers new versions itself when they come out.

Mac This device

macOS 13 Ventura or newer, Apple Silicon or Intel.

Download
  1. Open HotdogTV.dmg and drag Hotdog TV into Applications.
  2. The first time only, Control-click (or right-click) Hotdog TV in Applications, choose Open, then Open again.
  3. If your Mac only offers “Move to Bin” or “Done”, open System Settings › Privacy & Security, scroll down and choose Open Anyway beside Hotdog TV.

The app isn't signed with an Apple developer ID, which is why macOS asks. After the first time it opens normally, and updates install without asking.

Linux This device

64-bit PCs: Ubuntu 22.04, Fedora 36, Debian 12 or newer, and similar.

Download
  1. Make the file runnable: right-click › Properties › “Allow executing file as program”, or in a terminal chmod +x HotdogTV-x86_64.AppImage
  2. Double-click it, or run ./HotdogTV-x86_64.AppImage
  3. If it won't start, install FUSE 2: on Ubuntu 24.04 sudo apt install libfuse2t64, on Ubuntu 22.04 and Debian sudo apt install libfuse2, on Fedora sudo dnf install fuse-libs.

Optional

Hotdog TV Sync

A small server for a Windows PC, a Mac or a Linux computer that stays on (a Raspberry Pi will do). It keeps your playlists, favourites and settings the same on every TV box and computer. You don't need it to use Hotdog TV.

Windows
  1. Download it (one download for Apple Silicon and Intel Macs) and double-click it to unpack it.
  2. In Terminal: cd ~/Downloads/hotdogtv-sync-* and sudo sh install.sh
  3. Open the setup link it shows in a browser on any computer on your network, and make your admin login.

It starts with the Mac, before anyone signs in. Keep the Mac from sleeping, or devices can't reach it. To update, do the same with the newer download; your data is kept.

  1. Download the one for your computer: 64-bit PC, 64-bit ARM (Raspberry Pi 4 or 5 with a 64-bit system) or 32-bit ARM.
  2. Unpack it and run the installer: tar xzf HotdogTV-Sync-linux-*.tar.gz, then cd hotdogtv-sync-* and sudo ./install.sh
  3. Open the setup link it shows in a browser on any computer on your network, and make your admin login.

It runs as a service and starts with the computer (any Linux with systemd). To update, do the same with the newer download; your data is kept. If a firewall is on, let devices reach port 8920.
